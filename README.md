# CodeAlpha Banking System

A C++ banking system that manages customer accounts, deposits, withdrawals, transfers and transaction history.

## Features

- Create Account with auto-generated account number
- Deposit Money
- Withdraw Money (minimum balance of GHS 30 maintained)
- Check Balance
- View Transaction History
- Fund Transfer between accounts
- PIN protection with 20-minute lockout after 3 failed attempts
- Data persistence (accounts saved on exit)

## Prerequisites

- C++ compiler (g++ / MinGW)
- Git

## How to Run

1. Clone the repository:
   git clone https://github.com/Nartteh/CodeAlpha_Banking_System.git

2. Navigate into the folder:
   cd CodeAlpha_Banking_System

3. Compile the code:
   g++ main.cpp -o banking

4. Run the program:
   banking
